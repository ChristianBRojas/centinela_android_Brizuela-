# centinela_android_Brizuela-
🛡️ Centinela Android: Asistente interactivo de ciberseguridad en Python para entornos móviles (Pydroid 3/Termux). Permite escanear carpetas locales en busca de ejecutables de riesgo, auditar permisos abusivos del sistema mediante una guía interactiva y analizar enlaces (URLs) sospechosos para prevenir ataques de Phishing de forma preventiva.
